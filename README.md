# Dra. Mirian Agripino — prévia não oficial

Site estático em HTML/CSS/JS, adaptado do modelo Dra. Tamiris. Abra `index.html` ou publique os arquivos na raiz do repositório do GitHub Pages. Não requer npm nem build. Fontes, ícones e mapa dependem de internet.

## Antes de publicar
- Confirmar CRM, RQE, endereço, modalidades, telefones e destinos dos links encurtados diretamente com a profissional.
- Os textos são propostas editoriais, sujeitos à aprovação. O símbolo de coração é provisório, não a marca oficial.
- As fotos foram convertidas para WebP com nitidez leve, sem alteração geométrica ou generativa. A fotografia de atendimento com criança não aparece na página; mantida separadamente do site para avaliação de autorização de uso.
- O site usa noindex/nofollow para a prévia, o que não impede acesso público. Não há depoimentos inventados nem WhatsApp não confirmado.
